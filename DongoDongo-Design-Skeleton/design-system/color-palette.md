# Color Palette - Dongo Dongo Copilot Tutor

## Primary Colors (Cuphead Aesthetic)

| Color Name | Hex Code | Usage | Contrast Ratio on White | WCAG Status |
|------------|----------|-------|------------------------|-------------|
| **Ink Black** | `#1A1A1A` | Headings, Body Text, Outlines | 21:1 | ✅ AAA |
| **Paper White** | `#F5F1E8` | Background, Cards | N/A | Base |
| **Burgundy Red** | `#8B0000` | Alerts, CTAs, Accents | 5.9:1 | ✅ AA |
| **Mustard Yellow** | `#B8860B` | Highlights, Illustrations | 4.6:1 | ✅ AA |

## Accessibility Notes

- **Normal text** requires minimum 4.5:1 contrast ratio (WCAG AA)
- **Large text** (18pt+ or 14pt bold) requires minimum 3:1 contrast ratio
- All interactive elements must meet 3:1 minimum contrast
- High Contrast Mode compatibility required
